اختر المادة

اضغط على زر المادة لتحميل الأسئلة مباشرة، أو اضغط على زر التنزيل لحفظ ملف JSON واستخدامه عند ضعف الاتصال.

هيكل ملف JSON (لإنشاء ملفك الخاص)

يمكنك إنشاء ملف أسئلة خاص بك بالهيكل التالي:

  • كل سؤال يحتوي على question (نص السؤال) و answers (مصفوفة الإجابات)
  • كل إجابة تحتوي على text (نص الإجابة) و chosen (صح/خطأ)
  • يمكن أن يكون هناك أكثر من إجابة صحيحة ("chosen": true)
  • عدد الإجابات من 2 إلى 9 إجابات
{
  "messages": [
    {
      "poll": {
        "question": "نص السؤال هنا؟",
        "answers": [
          { "text": "الإجابة الأولى", "chosen": false },
          { "text": "الإجابة الصحيحة", "chosen": true },
          { "text": "إجابة أخرى", "chosen": false }
          { "text": "إجابة أخرى", "chosen": false }
        ]
      }
    },
